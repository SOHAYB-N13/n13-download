# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability in this project, please **do not** open a
public issue. Instead, report it privately by emailing the maintainer at
`97932683+SOHYAB-N13@users.noreply.github.com`.

Please include:

- The affected file(s) and a minimal reproducer
- A description of the impact
- Any suggested fix (optional)

We will acknowledge the report within 48 hours and keep you updated as the
issue is triaged and fixed. Once a fix is released, we are happy to credit the
reporter (unless they prefer to stay anonymous).
