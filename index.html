⬇️ TERMINAL DOWNLOAD MANAGER

N13 Download Manager

A fast multi-threaded download manager for Windows. Split downloads into parallel parts, resume anytime, schedule overnight downloads and send links straight from your browser.

View on GitHub Releases

Why N13 Download Manager?

⚡ Multi-threaded

Splits every download into parallel parts (up to 64 threads) for dramatically faster speeds.

▶️ Resume support

Interrupted or cancelled downloads restart exactly where they stopped — no wasted bandwidth.

🗓️ Scheduler

Start/stop windows and a night-time speed cap let the queue run itself while you sleep.

🌐 Browser integration

A Chrome extension, dldm:// protocol and local relay server capture links with one right-click.

📋 Clipboard monitor

Opt-in watcher that grabs a copied URL and queues it automatically.

🗄️ SQLite task store

Crash-safe queue and history database survives restarts without data loss.

✅ Checksum check

Verify every download against an MD5 or SHA-256 hash before it's done.

🖥️ Two interfaces

A polished Rich-based terminal UI and a dark modern web GUI (pywebview).

Quick start

pip install -r requirements.txt
python d.py --gui

Terminal UI: python d.py  ·  Direct download: python d.py "https://example.com/file.zip" -t 8

Install & run

# 1. Clone the repository
git clone https://github.com/SOHYAB-N13/n13-download.git

# 2. Install dependencies
pip install -r requirements.txt

# 3. Launch
python d.py # terminal interface
python d.py --gui # graphical interface
